📥 Import Rosters

Option A — FitnessGram roster export (recommended)

Upload the FitnessGram "All shown" export (.xlsx or .csv). Uses the Student Name ("Last, First"), Student Grade and Student Gender columns. There is no class column, so students are grouped by grade — rename each group in the preview. Anyone already on a roster is skipped. The older roster-app CSV (First Name, Last Name, Birthday, Class Name, Period, Age, Gender) still works too.

Option B — Paste simple JSON

Paste a JSON with class names and student names. First word = first name, rest = last name. Works with names from PowerSchool, class lists, etc.

Example format (click to copy): {"classes":[ {"className":"Kb","students":["Sam-Rivera","Alex-Chen","Mary Jane-Smith"]}, {"className":"Kc","students":["Jo-Park","Lee-Nguyen"]} ]} Use a hyphen (-) between first and last name. Multi-word first names work: "Mary Jane-Smith"
Option C — Use AI to extract from a school PDF

Copy the prompt below, paste it into any AI chat (ChatGPT, Gemini, Claude), and upload your attendance PDF. The AI returns JSON you paste here.

IMPORTANT: This contains confidential student information. Do not store, share, or reference any student names outside this conversation. Delete this conversation when finished. I am uploading class attendance audit PDF(s). For EACH class, extract: 1. The "Course" name (e.g. "Movement K") — use this as "className" 2. The "Section" number — use this as "period" 3. EVERY student listed Student names may be "LastName, FirstName MiddleName" (comma format) or "FirstName LastName" (no comma). - If there IS a comma: firstName = first word after the comma. lastName = word(s) before the comma. - If there is NO comma: firstName = first word. lastName = remaining words. Count EVERY student. Verify your count. Include students marked N/E. Output ONLY this JSON, no markdown, no explanation: {"classes":[{"className":"Movement K","period":"1","totalStudents":33,"students":[{"firstName":"Sam","lastName":"Rivera"},{"firstName":"Alex","lastName":"Chen"}]}]} Rules: - Include EVERY student - firstName = ONLY the first name - Multiple classes go in the "classes" array - Double-check your count matches totalStudents
⚠️ Always double-check your roster after import

One button saves everything into a single .rrbak file (a real archive package). Move that file to your new device (email, AirDrop, USB, cloud folder), then Import it.
